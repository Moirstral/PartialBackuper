How to use: 
	0. Install python. All packages in requirements, except jsonc, should come with python, pip install them if not
	1. Enter configs folder, copy an instance of config_template.json for each world you want to backup
		1.1. Now also accepts config files at different locations. Simply register the location in global_config.json
	2. Fill in backup configs for each world, w.r.t. explainations and examples inside the config file
	3. Run run_script.bat (or python script.py if you are not on windows)
	4. Backups will be created under the same folder your world is under
	5. How to recover: 
		- If you can accept un-backuped part keep to exist, then unzip and copy the backup into your world, replacing all files with the same name
		- If you can not accept that, then, with a reasonable config, the unzipped backup is itself a competent world you can drop in
